The funniest last words a phone says as its battery hits 1 percent.

> "If anyone finds this phone, tell my owner the charger was in the bag. The whole time. The bag."

`main.ts` (Node 22, stdlib only) writes exactly that line to `/output/entry.txt`.
See [METHOD.md](METHOD.md) for the 30-candidate tournament that picked it.
